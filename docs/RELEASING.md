# 发布说明

## 当前版本

WordGit 0.9.6 在 0.9.5 的基础上将提交、预览、恢复、导出与合并改为流式读写：文档不再整体进入内存，提交与取回的内存峰值与文档大小基本无关；存储格式与历史兼容性不变，无需迁移。0.9.5 整理了独立安装维护程序、ZIP 发布包和安装文档，保留 0.9.4 的旧拆包历史兼容修复。安装、升级与卸载均保留历史仓库和审阅稿。

本地生成发布包不代表已上传或公开发布。当前项目没有在本轮配置远程发布地址。

## 生成与发布

1. 在开发机运行 package.ps1 -Test，并执行 build.ps1 -WordTest。
2. 核对 EXE、ZIP 的版本与 SHA256SUMS.txt。
3. 在准备发布的位置上传两个安装文件和校验文件。
4. 发布说明写明验证过的 Windows、Word 位数、Git 版本和已知限制。
5. 公开源码前由维护者确定作者信息和许可证；正式分发时配置发布者代码签名。

当前安装包未进行代码签名，不能宣称已签名或已通过所有 Windows/Office 版本认证。现有 Word 实机验证以本机 64 位 Word 为准；32 位 Word 的注册路径有测试覆盖，完整功能仍需补充实机验证。

安装文件校验只验证包内数据是否完整。包本身的来源和发布者身份仍应通过可信发布渠道和代码签名确认。

## 升级与数据保护

安装器只操作 app 中已知的插件组件和当前用户注册信息，不删除 repositories、sessions 或源文档，也不运行仓库迁移、清理或重写命令。

发布前应保留跨格式回归测试：整包、旧拆包和新分块版本均能读取，混合历史可继续提交，压缩后旧版仍可取回。旧拆包版本只保证部件一致，不能补回该格式从未记录的原 ZIP 编码与时间戳。

## 本轮发布包范围

发布采用文件清单：插件 DLL、安装维护程序、启动脚本、README、使用与开发说明、发布说明和包内校验清单。用户数据、测试输出及恢复副本不属于发布内容。
